Robot Arm 4DOF — MIT App Inventor package

Files:
- คู่มือ_MIT_App_Inventor_แขนกล.pdf : detailed Thai guide
- RobotArm_BT4.ino : Arduino Nano + HC-06 + 4 Servo code
- MIT_App_Inventor_Blocks_Blueprint.txt : exact block blueprint

Important:
This package does NOT include an unverified .aia file. MIT App Inventor .aia files contain version-specific .scm/.bky project internals; the guide is designed so the project can be built directly in the current MIT App Inventor and avoids importing a stale/broken .aia.
